# 🇰🇷 K-EDU — The Korean Education Experience

Explore South Korea's education system through an interactive educational website.

K-EDU is a modern, responsive educational platform designed to help students understand South Korea's academic structure, school culture, university pathways, examinations, and international education opportunities.

## ✨ Features

- **Premium Interface:** Modern editorial-inspired design.
- **Education Stage Selector:** Explore four stages of the Korean education system.
- **Interactive Quiz:** Test your knowledge with a five-question quiz.
- **Learning Progress:** Track reading progress while exploring the website.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.
- **Educational Content:** Explore Korean school life, teaching methods, examinations, universities, hagwons, technology, and more.
- **Useful Resources:** Links to universities and scholarship information.

## 📚 Topics Covered

- Overview of Korean Education
- Education System Structure
- School Life in South Korea
- Teaching and Learning Methods
- Examinations and Suneung
- Korean Universities
- Hagwon Culture
- Educational Technology
- Korean Learning Culture
- International Students
- Korea vs. India Education Comparison
- Challenges in Korean Education

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension or your browser.
4. Explore the K-EDU website!

## 🎯 Project Goal

The goal of K-EDU is to present South Korea's education system in an engaging, accessible, and interactive way while demonstrating front-end web development skills.
